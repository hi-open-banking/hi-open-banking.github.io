## 版本号

API 版本位于路径中，例如 `/v1`。文档中的版本号与接口路径保持一致。

- **主版本**：不兼容变更，发布新的路径版本。
- **次版本**：新增字段或端点，向后兼容。
- **修订**：文档修正、错误码补充，不改变接口行为。

## 兼容性承诺

在同一个主版本内，我们承诺：

- 不删除或重命名已有字段
- 不改变已有字段的类型与含义
- 新增字段时，客户端应忽略未知字段
