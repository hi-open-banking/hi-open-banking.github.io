本站是开放银行相关标准、接入指南与 API 参考的中文文档站，面向需要接入开放银行能力的开发者与机构。

## 内容范围

- 开放银行基础概念与术语
- 授权、账户、支付等核心流程
- 接口约定、错误码与版本策略

## 维护方式

文档与站点代码一同维护。发现错误或有补充建议，欢迎通过仓库 Issue 反馈；涉及接口行为的疑问，请附带 `request_id` 与时间范围。

## 技术栈

站点使用 [Astro Starlight](https://starlight.astro.build/) 构建，输出纯静态文件，可部署在任意静态托管服务上。
