## Design principles

- **Consistent**: every API shares the same conventions for authentication, pagination, errors, and idempotency.
- **Secure**: least privilege by default; sensitive operations require explicit user consent.
- **Traceable**: every request carries a unique identifier for reconciliation and troubleshooting.
